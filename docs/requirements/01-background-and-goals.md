# 01 背景と目標

## 1. 背景

Bob's Used Books は実店舗を長く営んできた中古書店である。
店頭では「持ち込まれた本を検分して買い取り、棚に載せて売る」循環がすでに回っている。

この循環は **店の棚まで来られる人にしか届いていない。**
商圏の外の読者は買えず、蔵書を手放したい人は現物を持ち込めない。
本プロダクトは、この循環をオンラインへ広げる。

## 2. 目的

**中古書籍の買取から販売までを一店で完結させるオンライン店舗**を構築する。

大手マーケットプレイスへの相乗り出品と異なり、**店が 1 冊ずつ現物を検分し、
コンディションを分類し、仕入原価を知ったうえで値付けする。**
「どの 1 冊か」が分かることが、この店が選ばれる理由である。

したがってシステムが表現しなければならない最重要の事実は、
**「この 1 冊にいくら払い、いくらで売ったか」** である。

## 3. 事業の循環

```
顧客 ──買取オファー──> 店 ──棚入れ──> 在庫 ──注文──> 顧客
        （代金を支払う）              （売価をつける）
```

買取と販売は独立した二つの流れであり、**接点は棚入れただ一つ**である。
業務の詳細は [03 利用者と業務フロー](03-actors-and-business-flow.md) にある。

## 4. 効果測定指標

稼働後、店主が次の指標で効果を判定する。
システムはこれらを [ダッシュボード](04-functional-requirements.md#fr-adm-01) に表示する。

| 指標 | 定義 | 目標水準 |
| --- | --- | --- |
| オンライン注文件数 | 月次の確定注文件数（取消済を除く） | 稼働 3 か月後に店頭販売件数と同水準 |
| オンライン買取申込件数 | 月次の買取オファー件数 | 稼働 6 か月後に店頭持込件数の 3 割 |
| 粗利率 | 月次の粗利 ÷ 原価既知売上（税抜） | 店頭と同水準を維持 |
| 買取申込の支払到達率 | 支払完了に至ったオファー ÷ 申込オファー | 60% 以上 |
| かご投入 → 注文確定の転換率 | 注文確定数 ÷ かご投入セッション数 | 一般的な EC の水準 |

指標の算出ルールは [05 業務ルール §5](05-business-rules.md) が定める。

**粗利率の分母は「原価既知売上」である。** 仕入原価を持たない書籍の売上を分母に入れると
過小評価になる。この取り違えを防ぐため、ダッシュボードは分母となる金額を併記する。

## 5. 非ゴール

本件で **作らないと決めたもの**。判断の理由は [決定事項](decisions/README.md) にある。

| 作らないもの | 決定 |
| --- | --- |
| オンライン決済 | [ADR-0001](decisions/ADR-0001-defer-online-payment.md) |
| メール等のプッシュ通知 | [ADR-0002](decisions/ADR-0002-defer-notifications.md) |
| 店側からの買取査定額の提示（カウンターオファー） | [ADR-0003](decisions/ADR-0003-defer-counter-offer.md) |
| マーケットプレイス化（他店・個人の出品仲介） | 店が現物を検分しない本を売った時点で §2 の差別化が崩れるため |
| 新刊の取扱い | 仕入の構造が異なり、この店の強みが効かないため |
| 配送業者との連携（追跡番号・送り状） | [ADR-0002](decisions/ADR-0002-defer-notifications.md) と同じ理由。配送は店の既存運用で行う |

**ここに無いものが「やる」という意味ではない。**
引き受ける範囲は [02 スコープ](02-scope.md) が定める。
