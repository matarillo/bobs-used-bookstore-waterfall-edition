# ADR-0003 — 買取は顧客の希望額を承認／却下するだけとし、店側の査定額提示を持たない

| 項目 | 内容 |
| --- | --- |
| 決めた人 | 店主 |
| 影響する章 | [01 §5](../01-background-and-goals.md)、[03 §3](../03-actors-and-business-flow.md)、[05 §4](../05-business-rules.md)、[05 §8.2](../05-business-rules.md) |
| 金額・納期への影響 | 買取オファーの状態遷移が 6 状態で収まる。交渉の往復と、それに伴う画面・通知を見積から除外する |

## 決めたこと

買取の流れを「顧客が本の情報と**希望額**を申告 → 店は**承認か却下**」の二択に絞る。
店から金額を提示し直す（カウンターオファー）段階を設けない。

**買取価格の算定基準を店は持たない。** 値付けは顧客の申告に委ねる。

## そう決めた理由

- 店頭の買取では店が査定するのが常識だが、**オンラインでは現物が手元にない。**
  現物を見ずに店が出す査定額は結局「仮の額」であり、受領後に揉める。
  顧客に希望額を言わせ、店は受けるか断るかだけにするほうが流れが単純である。
- 交渉（提示 → 顧客の同意 → 再提示…）を入れると、状態遷移が倍に増える。
  状態が増えれば、画面の出し分け・権限・通知がすべて増える。
- 現物が申告と違ったときは、**受領済からの却下**で断れる（[D-17](README.md)）。
  交渉がなくても、店が損をする経路は塞げる。

## 採らなかった案とその理由

| 案 | 採らなかった理由 |
| --- | --- |
| 店側査定（受領後に店が額を確定） | 顧客は額が分からないまま現物を送ることになり、送ってもらう心理的障壁が上がる |
| カウンターオファー（交渉） | 状態遷移と画面が倍増する。フェーズ 2 の納期に収まらない |
| 相場データベース等による自動査定 | 外部依存が増えるうえ、中古本の価値は状態で大きく振れる。この店の「1 冊ずつ検分する」という強みとも合わない |

## 再訪の条件

却下が常態化する、または希望額が相場から大きく外れて折り合わないとき
（[RISK-01](../12-open-issues-and-risks.md)）。
その場合は「承認済（発送待ち）」の前に「店の提示額に顧客が同意する」段階を追加する。
**別契約として扱う。**
