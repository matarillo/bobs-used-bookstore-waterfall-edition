状態による差分

状態版面の変化
登録版面 1。入力欄は空
更新版面 1。既存の値が入り、現在の表紙画像が出る。仕入原価が書き換えられなくなり、 在庫数を変えると棚卸調整の理由の入力を求められる
棚入れ版面 2。見出しが替わり、案内が出て、書名・著者・ISBN・在庫数と分類 4 軸が 書き換えられなくなる。仕入原価は買取価格が入り、書き換えられない
入力に不備がある該当する欄の直下に ⚠ が出る。入力内容と選択肢は保たれる
表紙画像が安全でないと判定された表紙画像の欄に ⚠ が出る。書籍も画像も保存されない
