# 用語定義

本書群・画面・業務会話が共有する語彙。
**同じものを違う言葉で呼ばない／違うものを同じ言葉で呼ばない**ことがこの表の目的である。

画面に出す日本語表記は、この表の語に揃える。

## 1. 事業の骨格

Bob's Used Bookstore は **中古書籍を顧客から買い取り、顧客に売る** 店である。
したがって業務には対称な二つの流れがある。

| 日本語 | 英語 | 意味 |
| --- | --- | --- |
| 買取 | Buying | 顧客から書籍を買い取り、在庫にする流れ |
| 販売 | Selling | 在庫の書籍を顧客に売る流れ |
| 棚入れ | Stocking | 買い取った書籍を販売可能な在庫に変える行為。二つの流れをつなぐ唯一の接点 |
| 仕入原価 | Purchase Cost | その 1 冊に店が支払った金額 |
| 粗利 | Gross Profit | 売価と仕入原価の差。事業が成立しているかを示す指標 |

## 2. 中核の概念

| 日本語 | 英語 | 意味 |
| --- | --- | --- |
| 書籍 | Book | 販売可能な在庫としての 1 タイトル。中古書店では通常 1 冊 |
| 買取オファー | Offer | 顧客から店への「この本を買い取ってほしい」という申込 |
| 買い物かご | Shopping Cart | 顧客が購入しようとしている書籍の集まり |
| 欲しい物リスト | Wish List | 「今は買わない」印がついた書籍の集まり |
| 注文 | Order | 顧客と店の間で成立した売買の合意 |
| 注文明細 | Order Item | 注文に含まれる 1 書籍分の行 |
| 顧客 | Customer | 買う側にも売る側にもなりうる相手 |
| 配送先住所 | Address | 顧客の届け先 |
| 参照データ項目 | Reference Data Item | 書籍を分類するための選択肢 |

## 3. 分類の語彙

書籍と買取オファーは、いずれも同じ 4 軸で分類される。
4 軸はすべて **参照データ項目** という単一の概念から供給される。

| 日本語 | 英語 | 意味 |
| --- | --- | --- |
| 分類 | Classification | 4 軸の組。4 軸すべてが揃って初めて意味を持つ |
| 出版社 | Publisher | 分類の第 1 軸 |
| 書籍種別 | Book Type | 分類の第 2 軸（ハードカバー／ペーパーバック等） |
| ジャンル | Genre | 分類の第 3 軸 |
| コンディション | Condition | 分類の第 4 軸。中古書籍の傷み具合 |

> **注意**: 「コンディション」は書籍の物理的な傷み具合を指す。
> 注文や買取オファーの進行状況は「状態 (Status)」と呼び、別概念である。混同しない。

## 4. 在庫の語彙

| 日本語 | 英語 | 意味 | 0 冊を含むか |
| --- | --- | --- | --- |
| 在庫数 | Quantity | その書籍の手持ち冊数 | — |
| 在庫あり | In Stock | 在庫数が 1 以上 | 含まない |
| 在庫僅少 | Low In Stock | 在庫数がしきい値以下。**補充を判断するための概念** | **含む** |
| 在庫切れ | Out Of Stock | 在庫数が 0 | — |
| 棚卸調整 | Stock Adjustment | 注文以外の理由で店が在庫数を直す行為 |  — |
| 非公開 | Unlisted | 店頭の検索結果に出さない印 | — |

## 5. 金額と数量の語彙

| 日本語 | 英語 | 意味 |
| --- | --- | --- |
| 売価 | Price | 店が書籍を売る値段 |
| 買取価格 | Offer Price | 店が顧客に支払う（支払った）値段 |
| 小計 | SubTotal | 明細単位では 売価 × 数量、注文単位では明細小計の合計 |
| 税 | Tax | 小計に税率を乗じた額 |
| 合計 | Total | 小計 ＋ 税。**顧客に見せる額はこれである** |
| 粗利 | Gross Profit | (売価 − 仕入原価) × 数量。負になりうる |

## 6. 状態の語彙

### 6.1 注文の状態

| 日本語 | 英語 | 意味 |
| --- | --- | --- |
| 受付待ち | Pending | 顧客が注文を確定した直後 |
| 受付済 | Ordered | 店が注文を受け付けた |
| 出荷済 | Shipped | 店が発送した |
| 配達済 | Delivered | 顧客に届いた |
| 取消済 | Cancelled | 注文が取り消された。在庫は書籍に戻る |
| 納期超過 | Past Due | 納品予定日を過ぎてなお顧客に届いていない |

### 6.2 買取オファーの状態

| 日本語 | 英語 | 意味 |
| --- | --- | --- |
| 承認待ち | Pending Approval | 顧客が申し込んだ直後 |
| 承認済（発送待ち） | Approved | 店が承認し、顧客からの発送を待っている |
| 受領済 | Received | 顧客からの現物が店に届いた |
| 支払完了 | Paid | 店が顧客に代金を支払った |
| 却下 | Rejected | 店が申込を断った |
| 取下げ | Withdrawn | 顧客が自分で申込を取り下げた |
| 棚入れ済 | Stocked | 支払完了のオファーが販売在庫（書籍）になった |

## 7. 識別の語彙

| 日本語 | 英語 | 意味 |
| --- | --- | --- |
| 主体識別子 | Sub (Subject) | 外部の認証基盤が顧客に発行した不変の識別子。システムが顧客を特定する唯一の手段 |
| かご識別子 | Cart Id | 買い物かごを特定する識別子。ログインしていない訪問者にもかごを持たせるための鍵 |
| 供給元オファー | Source Offer | その書籍がどの買取オファーから生まれたかを示す参照 |
