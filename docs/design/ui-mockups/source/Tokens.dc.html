デザイントークンと部品

店が判断した情報（売価・コンディション・買取の値）だけを、すみれ色のインクで書く。書誌と見出しは Shippori Mincho で、操作と表は Zen Kaku Gothic New で書く。目立たせる要素はスリップだけにして、ほかは静かに保つ。

書体

一冊ずつ、確かめて。

主書体 Shippori Mincho（しっぽり明朝）。活版印刷の名残を持つオールドスタイルの明朝体。見出し、書名、店頭の地の文、合計額、スリップの売価。400 と 600 を使う

このサイトに並ぶ本は、どれも一度わたしたちの手を通っています。傷み具合を見て、値段をつけ、その一冊をそのままお届けします。

地の文は 17〜18px、行送り 1.95、1 行 34 字前後まで。見出しはプロポーショナル詰め（palt）と文節での改行（auto-phrase）

操作の文言、入力欄、表、管理画面は Zen Kaku Gothic New で組む。小さな字でも潰れにくい。

1,284件　4,890,510円

副書体 Zen Kaku Gothic New。本文 16px、補足 13.5〜14px。400・500・700 を使う。数字には単位を小さく添える

字の大きさの段: 60 / 44 / 36 / 24 / 18 / 16 / 14 / 13 px

スリップと表紙

古書店が本に挟む値札の短冊。表紙の上辺から覗かせ、税込の売価（とコンディション）を書く。在庫切れのときはグラシン色にして「在庫切れ」に替える。仮の表紙は書名を縦書きにし、右綴じの本として背を右に置く。
